# Flujo de Git de este repositorio (prevalece sobre cualquier steering global)

- Repositorio personal de una prueba técnica; NO usar kt, worktrees ni flujos corporativos.
- Una rama por spec: feat/<nombre-del-spec> (feat/foundation, feat/networking...), creada desde main con git checkout -b.
- Commits en formato Conventional Commits, en español.
- Al terminar un spec: merge a main mediante pull request en GitHub (feiahzeel/sdg-agente-conversacional).
